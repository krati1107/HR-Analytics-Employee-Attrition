# HR Analytics – Employee Attrition Analysis (Excel)

## Project Overview
This project focuses on analyzing employee data using Microsoft Excel to understand employee attrition, workforce demographics, and HR-related trends.

The objective is to help HR teams understand employee turnover patterns and make better workforce management decisions.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- GETPIVOTDATA
- KPI Analysis
- Data Visualization

## Key Analysis
- Employee attrition analysis
- Department-wise attrition
- Job role-wise attrition
- Age-group analysis
- Education-wise attrition
- Marital-status analysis
- Job satisfaction rating

## Dashboard KPIs
- Total Employees
- Attrition Count
- Average Age
- Active Employees
- Attrition Rate

## Project Workflow
1. Worked with employee data in Excel.
2. Organized and analyzed employee information.
3. Created Pivot Tables for different HR metrics.
4. Used Excel formulas to calculate KPIs.
5. Analyzed attrition across departments, job roles, age groups, and education levels.
6. Developed an HR analytics dashboard to present insights.

## Key Learning
- Practical experience with Excel-based HR analytics.
- Understanding employee attrition patterns.
- Working with Pivot Tables and KPI calculations.
- Converting raw employee data into meaningful business insights.
